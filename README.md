# Placement Management System

A web-based Placement Management System developed using Java Servlets, JSP, JDBC, MySQL and Apache Tomcat.

## Features

### Admin

- Admin Login
- Secure Logout
- Dashboard
- Manage Students
- Manage Companies
- Manage Jobs
- Manage Applications
- Update Application Status
- Download Student Resume

### Student

- Student Registration
- Student Login
- Student Dashboard
- View Jobs
- Apply for Jobs
- Upload Resume
- View Applications
- Logout

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Bootstrap
- Apache Tomcat 9

## Database

Tables used:

- admin
- students
- companies
- jobs
- applications

## Security

- Session Management
- Secure Logout
- Session Timeout
- Browser Back Button Protection
- Cache-Control Headers

## Installation

1. Import the project into Eclipse/STS.
2. Configure Apache Tomcat 9.
3. Import the MySQL database.
4. Run migration.sql if required.
5. Run the project on Tomcat.
